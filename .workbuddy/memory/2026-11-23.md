## 修复：参数绑定异常误报 500（浏览器测试揪出）

浏览器内 fetch 直打 `GET /api/vehicles`、`/api/credit-lines` 不带必填 `dealerId` 时返回 500 SYS_001，
根因 `MissingServletRequestParameterException` 被 web/common 两个 GlobalExceptionHandler 兜底到 handleUnknown。
前端每个视图都带 dealerId 所以正常，但 API 契约上缺参应是 400。
修复：两处 `GlobalExceptionHandler` 新增 `handleBadRequest`，接
`MissingServletRequestParameterException`/`MethodArgumentTypeMismatchException`/`HttpMessageNotReadableException`
→ 400 `VALID_001`（ErrorCode 既有）。浏览器测试加两条断言钉住（缺参返回 400 VALID_001 而非 500）。
